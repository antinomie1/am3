# Text fixture

`aegle-test-cjk.otf` and its [OFL.txt](OFL.txt) are copied unchanged from
Aegle's `tests/assets`, where the font's provenance and the script that
reproduces it are documented. It is a small subset of **Noto Sans CJK JP
Regular 2.004**, licensed under the SIL Open Font License 1.1, used by tests,
the gallery and the `thousand` example so that they render the same text on
every machine. It is not a bundled application font.
