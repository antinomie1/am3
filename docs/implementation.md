# 实现状态

本文件只记录已实现并验证过的内容。

## 已实现

- 配色：HCT（CAM16 + L*）与求解器、TonalSpot 方案的 47 个角色、四种模式、`Scheme::of` 线程缓存、`theme()` 生成 Aegle 主题、`am3.color.*` 令牌。`tests/color.rs`：基准种子 `#6750A4` 的浅/深色角色与 Material Color Utilities（Material Theme Builder 输出）一致到 ±2；5 个种子 × 4 种模式的文字对比度（普通 ≥ 4.5、高对比 ≥ 7）；四种模式生成的主题经 `Scheme::of` 还原为同一方案，Aegle 自带的深色与高对比主题得到对应模式。
- 令牌：字体角色、圆角刻度、高度阴影、expressive/standard 弹簧、状态层不透明度。
- 图标：SVG 路径解析（含弧线），39 个 Material Icons，按线程只解析一次；`icons::named` 按名称取图标。
- 按钮类：按钮（5 样式 × 5 尺寸 × 圆/方，切换）、图标按钮（4 样式 × 5 尺寸 × 3 宽度，切换）、FAB（3 尺寸 × 6 配色）与扩展 FAB。涟漪、状态层、键盘焦点环、圆角形变与高度弹簧动画。`tests/buttons.rs`：切换按钮的翻转与回调、种类随切换变化；尺寸变化重新布局并按新字体角色重排标签（改文字后保持）；固定宽度；指针获焦不显示焦点、按键后显示。
- 组合按钮：标准/连接按钮组（5 尺寸，单选/多选）、分割按钮（4 样式，内侧角随悬停/焦点/按下变圆，菜单打开时变圆并翻转箭头）、分段按钮（单选/多选、对勾）、FAB 菜单（开合、关闭按钮、依次升起的菜单项）。尺寸与圆角取自 m3.material.io 的令牌表（分割按钮 xsmall/small 与连接组 small 已逐项核对，其余尺寸按同一规律）。`tests/groups.rs`：单选组恰好一个选中且再次点选不变、连接组间距 2 dp；标准组按下时左邻按钮的绘制右缘收回、松开后复原且布局不变；分割按钮菜单部分报告打开且保持普通配色；多选分段的选中索引；FAB 菜单打开后菜单项可见、点选后关闭。
- 选择控件与滑块：复选框（不确定、错误）、单选按钮（互斥、方向键）、开关（手柄图标、按下放大）、滑块（5 尺寸、离散停止点、范围、居中、数值气泡）。`tests/selection.rs`：点击复选框清除不确定状态；单选按钮点击与上下键循环选择；开关两次点击报告两次改变；滑块拖动到 75%、步长 10 下右方向键到 90、Home 到 0；范围滑块按下取较近手柄，拖过终点时两端一致、起点不超过终点。
- 纸片与指示器：四种纸片及 elevated 变体、线性/圆形进度（确定、不确定、波浪）、加载指示器（七种近似形状的变形与旋转，contained 变体）。`tests/chips.rs`：筛选纸片选中后变宽；输入纸片点击标签报告点击、点击尾随图标与按 Delete 报告移除且不报告点击；进度值钳制到 0–1，波浪使线性高度为 10 dp、圆形为 48 dp。

- 预览：`examples/gallery` 生成 `docs/images/*.png`，已逐张目视检查浅色与深色。
- 交互展示：`examples/showcase` 是工作区中的独立包 `am3-showcase`（作为 am3 的 dev-dependency，`aegle` 门面会让 `element!` 的展开路径指向 `::aegle::loader`，库本身因此无法编译）。原生窗口里用导航栏杆分为按钮、选择、输入、容器与浮层、导航五页；顶部的种子色分段按钮与深色、高对比开关经 `Window::set_theme` 换主题，减少动态效果开关经 `Window::set_reduced_motion`，初值取系统偏好。默认用 Rust API 构建，`--markup` 用 `ui!` 编译 `showcase.aegle` 及其导入的页面组件；两条路径把同一组句柄交给 `shell::wire`，菜单、分割按钮菜单与两种工具提示（没有标记元素）也在那里挂到 `id` 句柄上。在 Windows 11 上运行两个版本并截图核对：两者首屏一致，深色与种子色切换、翻页、对话框、模态日期选择器正常。标记版本中模态日期/时间选择器、抽屉与提示条被“取消”、scrim 或关闭按钮关上时不写回 `open` 状态，打开按钮因此先清再设该状态。
- 颜色令牌注册：`color::register_tokens` 注册全部角色令牌，`theme()` 与 `elements()` 调用它，所以标记语言的 `token("am3.color.…")` 不再依赖 Rust 代码先调用过 `Role::token`（此前标记版本展示因此加载失败）；`tests/markup.rs` 覆盖。

## 性能

`cargo run --example thousand --release`（无窗口、Aegle 的 CJK 测试字体、计数全局分配器，`visit_scenes` 录制场景但不光栅化；i5-13600KF，三次运行）。界面为 125 行，每行文字、填充按钮、复选框、开关、滑块、筛选纸片、标准图标按钮与线性进度，共 1000 个控件；同时用 Aegle 默认控件搭同样的 125 行作对照（先构建，承担字体缓存的冷启动）。

| 场景 | am3 | Aegle 默认控件 |
| --- | --- | --- |
| 首帧（构建、布局、录制） | 4.36–4.42 ms，19,929 次分配（不先构建对照、承担冷启动时 5.1 ms） | 4.06–4.18 ms，14,926 次分配 |
| 构建后存活堆 | 5,089 KiB（动画稳定后） | 4,235 KiB |
| 空闲 refresh | 22.9–23.0 µs，4 次分配 | 22–24 µs，4 次（Aegle `thousand`） |
| 改一个滑块值 | 23.3–23.6 µs，25 次分配 | |
| 悬停移动 | 37.3–37.6 µs，7 次分配 | 31–33 µs，7 次（Aegle `thousand`） |
| 切换浅/深主题并出一帧 | 0.72 ms，约 5,000 次分配（每个控件启动一次颜色过渡） | |
| 标记加载：检查、构建 1000 个 `Md*` 元素并出首帧 | 4.86–4.96 ms，24,073 次分配 | |

- 配色：`Scheme::from_seed` 每次 463–467 µs、无分配（47 个角色各做一次 HCT 二分求解）；只在主题第一次出现时计算，之后 `Scheme::of` 命中线程缓存为 26 ns，皮肤每次绘制直接调用。
- 空闲：动画与颜色过渡结束后 `wants_frames` 为假（构建后、悬停离开后、切换主题后都检查过），不请求帧；`tests/buttons.rs` 检查悬停升起的弹簧结束后不再请求帧。
- 滑块改值比空闲多 21 次分配：圆角不同的轨道段每次重绘都重建路径。只在值变化的那一帧发生，时间与空闲相当，未做优化。

## 依赖 Aegle 的改动

- 种类皮肤随控件类型改变重新解析（Aegle 提交 b201d1d）。
- `Control::text_viewport` 与 `Editor::changes()`（Aegle 提交 14d23fe），供文本框外框声明文字区域并读取编辑变更。
- 为 am3 在 Aegle 中加入的通用接口（Aegle 提交 62a733e）：`Control::text_role`（控件的文字排版角色）、焦点可见语义（`VisualState::focused` 只在键盘焦点时为真，`Node::is_focused` 查询逻辑焦点）。

## 已知限制

- 轮播只有无约束布局，没有 multi-browse/hero 的项目遮罩与缩放。
- 搜索只有停靠视图，没有全屏搜索视图。
- 日期与时间的文字（月份、星期、“Select date”）是英文，未本地化；周从星期日开始。
- 文本框的文字布局与图标位置只按从左到右排列。
- 时间选择器 AM/PM 两半的四角都是 7 dp 圆角，没有按外侧/内侧区分。
- 底部表不能拖动关闭；普通工具提示显示在指针处。
- 菜单与富工具提示没有标记元素；导航栏杆的头部（菜单按钮、FAB）只能在 Rust 中添加。
- 加载指示器的形状是极坐标近似；非对称形状的按下状态层是均匀的；滑块只有横向；FAB 菜单没有退出动画。
